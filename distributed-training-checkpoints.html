Distributed Training System w/ Checkpoints
Designing an end-to-end distributed ML training system with fault-tolerant checkpointing.
View on GitHub ←

Tech Stack

  • Rust (core runtime)
  • Python (client-facing APIs)
  • gRPC (communication among nodes)
  • Checkpoint storage + metadata (TBD: filesystem/S3 + index)

PRD

Provide a reliable way to submit distributed training jobs. The system should automatically distribute work to workers, periodically write consistent checkpoints, and resume from the latest checkpoint after failures without losing meaningful progress.

Tasks

  • Define job specification format (TOML) + validation
  • Implement coordinator orchestration and worker lifecycle
  • Design checkpoint protocol and consistency guarantees
  • Implement failure detection and resumption flow
  • Create an end-to-end test plan for partial failures
